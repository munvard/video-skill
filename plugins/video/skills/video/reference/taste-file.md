# The taste file: `.video/taste.md`

This is how the skill learns one user's taste. It lives in the user's project (or home folder for films with no
project), never in the skill. Read it before every concept. Its rules win over the general craft rules.

## When to write
- Every time the user reacts to a film, a still, a look gate or a concept: the same day, before more work.
- Copy their words exactly, typos and capitals included. Their words carry the feeling; a summary loses it.
- Write the rule the words give: one line a stranger could follow on the next film.
- Merge when a new verdict repeats an old rule: add the new quote to the same row. Keep the file short.

## Format
```
# Taste

| Date | Film | Their words | The rule |
|---|---|---|---|
| November 3, 2026 | launch v1 | "too dark, it looks like a funeral" | Bright, lit worlds; dark only as a short night beat. |
| November 4, 2026 | launch v2 | "YES this one. the glass part is fire" | Keep the glass world; it is the base of the next version. |

## Rules in force (newest wins)
1. Bright, lit worlds; dark only as a short night beat.
2. ...
```

## How to use it
- Before concepts: list the rules in force and check each concept against them. Say which rule shaped the pick.
- Before showing a draft: check it against every rule. A draft that breaks one is not shown.
- A loved film is a base: keep its story and beats and make every second better, unless the user asks for a new idea.
- When the user says a film is bad without saying why, ask one short question: what felt wrong first?
