# Terminal poem

Family: Screen and UI. Status: draft.

Only text, and something huge happens.

- **Use it for:** Developer tools, command line apps.
- **Not for:** A general audience with no context.
- **Look:** One dark terminal, perfect type, one accent.
- **Motion:** Real typing rhythm, then the text leaves the terminal.
- **Type:** Monospace, large.
- **Sound:** Keys, one low hit on enter.
- **Build with:** Canvas, real output only.
- **Hook:** One command with a surprising promise.
- **It fails when:** Fake output, code nobody can read.
