# Wait for it

Family: Social speed. Status: draft.

A question you can only answer by staying.

- **Use it for:** A surprising real result.
- **Not for:** A weak result.
- **Look:** One clear test, one fixed camera.
- **Motion:** Small progress, one false end, then the result.
- **Type:** The question stays on screen.
- **Sound:** Tension that drops away.
- **Build with:** Real test, or a 3D simulation named as one.
- **Hook:** "Will it?" with the risk already visible.
- **It fails when:** Cheating, a long wait, no payoff.
