# The cursor is the hero

Family: Screen and UI. Status: draft.

A tiny character with a job.

- **Use it for:** Productivity tools, automation.
- **Not for:** Voice or mobile only products.
- **Look:** A large cursor with light and shadow over simple interface shapes.
- **Motion:** It hesitates, hurries, gets help, rests.
- **Type:** Few words near the action.
- **Sound:** Foley for each move.
- **Build with:** Canvas or 3D cursor over stylised UI.
- **Hook:** The cursor gives up.
- **It fails when:** The cursor only moves from button to button.
