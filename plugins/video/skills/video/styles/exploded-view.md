# Exploded view

Family: Cinematic 3D. Status: draft.

The object opens and explains itself.

- **Use it for:** Hardware, engineering, an app shown as layers.
- **Not for:** Products with nothing inside to show.
- **Look:** Studio sweep, parts in exact alignment, one accent color.
- **Motion:** Parts separate along one axis, pause, snap back on the beat.
- **Type:** Plain names only for parts that matter.
- **Sound:** Mechanical clicks, one clean whoosh only when parts move.
- **Build with:** Blender, parts parented to one driver.
- **Hook:** It comes apart in the first second.
- **It fails when:** Labels on everything, or parts fly at random.
