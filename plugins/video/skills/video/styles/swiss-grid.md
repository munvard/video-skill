# Swiss grid

Family: Minimal motion. Status: draft.

A poster that moves.

- **Use it for:** Studios, conferences, editorial, fintech.
- **Not for:** Warm family products.
- **Look:** Strict grid, one red or blue accent, large numbers, real whitespace.
- **Motion:** Blocks slide on the grid with hard stops.
- **Type:** Grotesque, left aligned, extreme size contrast.
- **Sound:** Dry clicks and a steady kick.
- **Build with:** HTML with a visible grid system.
- **Hook:** One giant number or letter slides into place.
- **It fails when:** The grid is only decoration.
