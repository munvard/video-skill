# Time machine

Family: Data and explanation. Status: draft.

One object through many years.

- **Use it for:** History, anniversaries, product progress.
- **Not for:** Invented dates.
- **Look:** The same framing, the world changes around it.
- **Motion:** A locked camera, match cuts, one speed-up.
- **Type:** The year, large.
- **Sound:** Era sounds through one melody.
- **Build with:** 3D or real archive with rights.
- **Hook:** The oldest version, in close-up.
- **It fails when:** Wrong facts, too many stops.
